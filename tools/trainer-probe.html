Trainer probe

Connects to a trainer over Bluetooth, lists what it offers and logs everything it sends, so we can work out how to set its resistance. Close every other app connected to the trainer first (nRF Connect, Bkool, Zwift): it takes one Bluetooth connection at a time.

Send a command

Pick where to write, type bytes in hex (or use a preset, which fills the box), then Send. Pedal gently while you try resistance commands, so you can feel a change. Only write to the f03ee002 characteristic for now; leave the beefe… ones alone until we know what they do.
